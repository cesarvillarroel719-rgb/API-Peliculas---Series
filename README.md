# API de Películas y Series 🎬

Proyecto backend desarrollado en Django que incluye una página de bienvenida personalizada y control de errores 404.

---

## 🚀 Guía rápida de ejecución local

Abre tu terminal, copia y ejecuta todos los comandos de la siguiente sección en orden:

```bash
# 1. Descarga el repositorio desde GitHub a tu computador (cmd)
git clone https://github.com/cesarvillarroel719-rgb/API-Peliculas---Series

# 2. Entra a la carpeta principal del proyecto recién descargado (cmd)
cd API-Peliculas---Series

# 3. Crea un ambiente virtual de Python llamado .venv en el directorio (cmd)
python -m venv .venv

# 4. Activa el ambiente virtual para aislar las dependencias (cmd del directorio principal)
.\.venv\Scripts\Activate.ps1

# 5. Instala las librerías necesarias registradas en el archivo requirements.txt (cmd)
python -m pip install -r requirements.txt

# 6. Inicia el servidor de desarrollo local de Django (cmd del directorio principal)
python manage.py runserver
